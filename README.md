# Ghusn Maintenance — preview build

Compiled output of the public website for **مؤسسة غصن للصيانة / Ghosn
Maintenance Establishment**, published to GitHub Pages.

**Live:** https://boogywithhoody.github.io/ghusn-maintenance-site/

This repository holds only generated files — the HTML, CSS, JavaScript, and
images a browser downloads when it loads the site. The application source
lives in a separate private repository and is not published here.

This is a **preview**. Static hosting runs no server code, so the service
request form, the quote form, and the admin dashboard are disabled, and the
pages say so. Search engine indexing is turned off site-wide.

Do not edit files here by hand; they are overwritten on each build.
